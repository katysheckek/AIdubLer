# AIdubLer
### AI-Powered Adaptive Learning Platform

An AI-powered platform for studying your own materials with a personal AI tutor. Users upload documents, explore them through explanations and dialogue, complete practice activities, receive feedback, and track their progress.

> **Important:** This project is intended for a Russian-speaking audience. The AI assistant must analyze uploaded texts and communicate with users in Russian: the interface, explanations, questions, tests, feedback, and recommendations must be in Russian.

## What the Product Does

- Create learning projects and folders.
- Upload materials: documents, articles, notes, and presentations.
- Structure materials into topics and key concepts.
- Generate text-based explanations based on uploaded materials.
- Chat with an AI tutor: ask questions, request examples, and discuss difficult topics.
- Generate questions and interactive tests.
- Evaluate answers and provide feedback.
- Identify topics that require further practice.
- Visualize progress and recommend next learning activities.

## Core User Flow

The user creates a project, uploads materials, studies the structured content, talks with the AI tutor, completes tests, and receives recommendations for further topics.

## MVP

The first version includes:

- Text-based study of uploaded materials.
- An AI tutor in a chat format.
- Questions, tests, and automated feedback.
- Progress tracking by topic and project.
- Recommendations for review and further learning.

## Not Included in MVP

- Audio and video generation.
- Subtitles and subtitle synchronization.
- Real-time voice conversations with the AI.
- Fully automated long-term personalized learning paths.

## Limitations

- The AI may make mistakes or misinterpret materials; responses should be grounded in uploaded sources and allow verification.
- Processing large documents and generating responses may take time.
- Using external AI services creates API costs.
